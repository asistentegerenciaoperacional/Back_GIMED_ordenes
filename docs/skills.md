# Skills de ingeniería

El front y el back incluyen `improve-codebase-architecture`, `codebase-design` y `tdd` desde [mattpocock/skills](https://github.com/mattpocock/skills/tree/5863806dd4e15c63174bee4e7515a4256792ecfa), con licencia MIT. En GIMED, `CONTEXT.md` es el glosario del dominio. Las skills `gimed-*` describen las comprobaciones propias de la aplicación.

La prioridad de refactor es separar persistencia de reglas, reducir el contexto inicial por flujo y usar consultas paginadas en las vistas con mayor volumen. Mantener una prueba de caracterización por comportamiento delicado antes de moverlo.
